# User flow
와이어 프레임을 바탕으로 모바일 userflow를 정의
와이어 프레임 노션 공유 문서 참조

# 화면 종류

S01 홈 화면
S02 음성 인식 화면
S03 내용 확인 화면
S04 추가 질문 화면
S05 사건 카드 확정 화면
S06 사건번호 및 비밀번호 설정 화면
S07 가이드 화면
S08 이전 사건 조회 화면 
S09 서류함 화면
S10 지도 화면
S11 경찰서 대응 화면

# 표기 규칙 

- `UI`: 프론트엔드에서 고정 구현
- `USER`: 사용자가 입력하는 정보
- `AI`: AI가 분석하거나 생성하는 정보
- `API`: 서버·DB에서 전달받는 정보
- `STATE`: 로딩·오류·완료 상태에 따라 달라지는 영역

# S02. 음성 인식 화면

## 화면 구성

| 화면 요소 | 구분 | 내용 |
|-----------|------|------|
| 뒤로가기 버튼 | `UI` | 이전 화면으로 이동하는 버튼 |
| 신고 유형 제목 | `UI` | 현재 신고 유형인 분실·도난 신고 표시 |
| 진행 단계 | `UI` | 전체 6단계 중 현재 단계인 3단계 표시 |
| 화면 제목 | `UI` | 사건 경위를 말해 달라는 안내 문구 표시 |
| 화면 설명 | `UI` | 사건 경위를 말하면 신고서 초안을 자동 작성한다는 설명 표시 |
| 음성 녹음 버튼 | `UI` | 음성 녹음 기능을 나타내는 마이크 버튼 |
| 녹음 상태 | `STATE` | 녹음 중 여부 표시 |
| 녹음 시간 | `STATE` | 현재 음성 녹음 경과 시간 표시 |
| 음성 인식 내용 | `AI` | 사용자 음성을 실시간으로 변환한 텍스트 표시 |
| 녹음 중지 버튼 | `UI` | 진행 중인 음성 녹음을 종료하는 버튼 |
| 다시 녹음 버튼 | `UI` | 기존 녹음 및 인식 내용을 초기화하고 다시 녹음하는 버튼 |
| 텍스트 입력 버튼 | `UI` | 사건 경위를 직접 입력하는 방식으로 전환하는 버튼 |
| 현재 위치 | `API` | 기기에서 확인한 사용자의 현재 위치 표시 |
| 현지 시간 | `API` | 현재 위치를 기준으로 한 현지 시간 표시 |
| 오프라인 안내 | `UI` | 오프라인 환경에서도 음성 인식이 가능하다는 안내 표시 |

## 화면 이동

| 선택 요소 | 조건 | 결과 |
|-----------|------|------|
| 뒤로가기 | 항상 | S01 홈 화면으로 이동 |
| 녹음 중지 | 인식된 음성 내용 있음 | 녹음을 종료하고 S03 내용 확인 화면으로 이동 |
| 녹음 중지 | 인식된 음성 내용 없음 | S02 화면을 유지하고 사건 경위 입력 안내 표시 |
| 다시 녹음 | 항상 | 기존 녹음 및 인식 내용을 초기화하고 새 녹음 시작 |
| 텍스트 입력 | 항상 | 음성 녹음을 중지하고 직접 입력 모드로 전환 |





# S03. 내용 확인 화면

## 화면 구성

| 화면 요소 | 구분 | 내용 |
|-----------|------|------|
| 뒤로가기 버튼 | `UI` | 이전 화면으로 이동하는 버튼 |
| 화면 제목 | `UI` | 인식된 사건 내용이 맞는지 확인하는 문구 표시 |
| 진행 단계 | `UI` | 전체 6단계 중 현재 단계인 3단계 표시 |
| 진행 표시줄 | `STATE` | 전체 과정에서 현재 진행 정도 표시 |
| 녹음된 내용 제목 | `UI` | 음성 인식 결과 영역의 제목 표시 |
| 녹음된 내용 | `AI` | S02에서 사용자 음성을 텍스트로 변환한 사건 경위 표시 |
| 내용 수정 버튼 | `UI` | 녹음된 사건 경위를 직접 수정할 수 있는 버튼 |
| 수정된 사건 내용 | `USER` | 사용자가 직접 수정한 사건 경위 저장 |
| 다시 녹음하기 버튼 | `UI` | 사건 경위를 음성으로 다시 입력하는 버튼 |
| 현재 위치 수정 버튼 | `UI` | 자동으로 확인된 사건 발생 위치를 수정하는 버튼 |
| 수정된 현재 위치 | `USER` | 사용자가 직접 수정한 사건 발생 위치 저장 |
| 발생 시간 수정 버튼 | `UI` | 자동으로 확인된 사건 발생 시간을 수정하는 버튼 |
| 수정된 발생 시간 | `USER` | 사용자가 직접 수정한 사건 발생 시간 저장 |
| AI 분석 안내 | `UI` | 입력 내용을 바탕으로 제출용 피해신고서 초안을 자동 구성한다는 안내 표시 |
| 제출 서류 유형 | `AI` | 사건 내용을 분석해 생성할 피해신고서 유형 표시 |
| 이 내용으로 분석하기 버튼 | `UI` | 확인한 사건 내용을 AI 분석 단계로 전달하는 버튼 |
| 분석 진행 상태 | `STATE` | 분석 요청의 로딩·완료·오류 상태 표시 |

| 이 내용으로 분석하기 | 사건 내용 있음 | 입력 내용을 분석하고 S04 추가 질문 화면으로 이동 |
| 이 내용으로 분석하기 | 사건 내용 없음 | S03 화면을 유지하고 사건 내용 입력 안내 표시 |
| 이 내용으로 분석하기 | 분석 실패 | S03 화면을 유지하고 재시도 안내 표시 |




# S04. 추가 질문 화면

## 화면 구성

| 화면 요소 | 구분 | 내용 |
|-----------|------|------|
| 뒤로가기 버튼 | `UI` | 이전 화면으로 이동하는 버튼 |
| 신고 유형 제목 | `UI` | 현재 신고 유형인 분실·도난 신고 표시 |
| 진행 단계 | `UI` | 전체 6단계 중 현재 단계인 3단계 표시 |
| 진행 표시줄 | `STATE` | 전체 과정에서 현재 진행 정도 표시 |
| 질문 유형 | `AI` | 사건 신고에 필요한 추가 정보의 유형 표시 |
| 추가 질문 | `AI` | 사건 분석 결과를 바탕으로 부족한 정보를 확인하는 질문 표시 |
| 답변 안내 | `AI` | 질문에 맞는 선택 방법과 복수 선택 가능 여부 안내 |
| 선택 답변 목록 | `AI` | 질문에 따라 선택 가능한 답변 항목 표시 |
| 선택된 답변 | `USER` | 사용자가 선택한 하나 이상의 답변 저장 |
| 기타 답변 | `USER` | 선택 목록에 없는 내용을 사용자가 직접 입력 |
| 이전으로 버튼 | `UI` | 직전 추가 질문으로 돌아가는 버튼 |
| 잘 모르겠어요 버튼 | `UI` | 해당 질문에 답하기 어려운 경우 선택하는 버튼 |
| 답변 완료 버튼 | `UI` | 현재 답변을 저장하고 다음 질문으로 진행하는 버튼 |
| 질문 진행 상태 | `STATE` | 전체 추가 질문 중 현재 질문의 순서와 완료 여부 표시 |
| 기획 확인 안내 | `UI` | 필수·선택 질문 구분 및 복수 선택 방식에 대한 안내 표시 |
| 하단 내비게이션 탭 | `UI` | 사건·가이드·서류 탭 표시 |

## 화면 이동

| 선택 요소 | 조건 | 결과 |
|-----------|------|------|
| 뒤로가기 | 항상 | S03 내용 확인 화면으로 이동 |
| 답변 항목 선택 | 단일 선택 질문 | 기존 선택을 해제하고 선택한 답변 저장 |
| 답변 항목 선택 | 복수 선택 질문 | 선택한 답변을 추가하거나 선택 해제 |
| 기타 | 항상 | S04에서 기타 답변 직접 입력 영역 표시 |
| 잘 모르겠어요 | 항상 | 현재 질문의 답변을 모름으로 저장 |
| 이전으로 | 이전 질문 있음 | 직전 질문과 저장된 답변 표시 |
| 이전으로 | 이전 질문 없음 | S03 내용 확인 화면으로 이동 |
| 답변 완료 | 필수 답변 없음 | S04 화면을 유지하고 답변 선택 안내 표시 |
| 답변 완료 | 다음 질문 있음 | 현재 답변을 저장하고 다음 추가 질문 표시 |
| 답변 완료 | 마지막 질문이며 필수 답변 완료 | 추가 답변을 사건 정보에 반영하고 S05 사건 카드 확정 화면으로 이동 |
| 하단 사건 탭 | 항상 | 현재 S04 화면 유지 |
| 하단 가이드 탭 | 활성 사건 있음 | S07 가이드 화면으로 이동 |
| 하단 서류 탭 | 활성 사건 있음 | S09 서류함 화면으로 이동 |

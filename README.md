# Travel Guard

해외여행 중 발생한 분실·도난 사고를 신고부터 사후 처리까지 안내하는 여행 안전 지원 서비스입니다.

사용자가 사건 상황을 음성 또는 텍스트로 입력하면 사건 정보를 구조화하고, 사건 카드를 바탕으로 지금 해야 할 일을 단계별로 안내합니다. 가까운 경찰서·영사관 등 관련 기관을 찾고, 경찰과의 실시간 대화 통역과 신고서·보험 서류 준비까지 한 흐름 안에서 지원하는 것을 목표로 합니다.

## 주요 기능

- 로그인 없이 분실·도난 사건 접수 시작
- 음성 또는 텍스트 기반 사건 입력
- AI를 이용한 사건 유형 분류와 추가 질문
- 사건 정보·피해 물품·발생 위치를 담은 사건 카드 생성
- 사건번호와 비밀번호를 이용한 사건 저장·재조회
- 사건 상황에 따른 행동 가이드와 진행 상태 관리
- 현재 위치 기반 인근 경찰서·영사관·관련 기관 조회
- 기관까지의 이동 경로 안내
- 경찰과의 실시간 음성 대화 및 통역 지원
- 신고서 사진 촬영·업로드와 문서 검토 흐름
- 신고서 초안 생성 및 보험 청구에 필요한 서류 안내
- 작성 중 사건과 완료된 사건의 문서 허브 관리

## 서비스 이용 흐름

Travel Guard는 사고가 발생한 순간부터 사용자가 필요한 대응을 마칠 때까지의 과정을 하나의 흐름으로 연결합니다.

1. 사용자가 음성 또는 텍스트로 분실·도난 상황을 설명합니다.
2. AI가 사건 유형과 핵심 정보를 정리하고, 부족한 내용은 추가로 질문합니다.
3. 사용자는 정리된 내용을 확인하고 사건 카드로 저장합니다.
4. 사건 상황과 위치를 바탕으로 지금 해야 할 행동과 필요한 준비물을 안내받습니다.
5. 가까운 경찰서·영사관 등 관련 기관과 이동 경로를 확인합니다.
6. 필요하면 경찰과의 대화 통역, 신고서 작성, 서류 준비를 이어서 진행합니다.
7. 사건번호와 비밀번호를 통해 나중에 사건과 진행 상황을 다시 확인합니다.

## 핵심 기능

### AI 기반 사건 접수

사용자는 복잡한 양식을 처음부터 작성하지 않고 사고 상황을 자연스럽게 말하거나 입력할 수 있습니다. AI는 입력 내용을 분실·도난 사건에 필요한 정보로 정리하고, 사건 유형·발생 장소·시간·피해 물품 등 핵심 항목을 구조화합니다. 정보가 부족한 경우에는 추가 질문을 통해 신고에 필요한 내용을 채웁니다.

### 사건 카드

정리된 사건 정보는 사건 카드로 한눈에 확인할 수 있습니다. 사건 유형, 발생 일시와 장소, 피해 물품, 사건 요약 등을 하나의 기준 정보로 관리해 이후 가이드·신고·보험 관련 기능에서 일관되게 사용할 수 있습니다.

### 상황별 행동 가이드

사건 카드와 현재 위치를 바탕으로 사용자가 먼저 해야 할 일을 우선순위에 따라 안내합니다. 각 단계에는 행동 내용, 필요한 이유, 준비물, 문의 기관과 완료 상태가 포함되어 사용자가 당황하지 않고 순서대로 대응할 수 있습니다.

### 주변 기관 및 길찾기

현재 위치나 직접 입력한 장소를 기준으로 가까운 경찰서, 영사관, 관련 기관을 찾을 수 있습니다. 기관의 주소와 거리, 운영 정보, 연락처를 확인하고 목적지까지의 이동 경로를 안내받을 수 있습니다.

### 경찰 대화 통역

현지 경찰과 대화해야 하는 상황에서 음성 기반 실시간 통역을 지원합니다. 여행자의 상황 설명과 경찰의 안내를 서로 이해할 수 있는 언어로 전달해 신고 과정의 의사소통을 돕습니다.

### 신고서 및 문서 지원

신고서 초안을 작성하고, 신고서 사진이나 파일을 등록해 필요한 정보를 검토할 수 있습니다. 문서에 포함된 사건 정보와 누락된 항목을 확인해 신고 준비를 돕고, 관련 서류를 사건별로 관리할 수 있습니다.

### 보험 청구 안내

보험 상품과 사건 유형에 따라 필요한 서류, 보상 청구에 참고할 정보, 후속 처리 절차를 안내합니다. 사용자가 보유한 보험 정보와 공식 자료를 바탕으로 보험 청구 준비에 필요한 내용을 확인할 수 있습니다.

### 사건 보관 및 재조회

사건 접수 시 발급된 사건번호와 사용자가 설정한 비밀번호로 이전 사건을 다시 불러올 수 있습니다. 저장된 사건 카드와 서류, 가이드 진행 상황을 확인해 사고 이후의 후속 처리를 이어갈 수 있습니다.

## 시작하기

### 요구 사항

- Node.js
- pnpm 10 이상
- PostgreSQL 또는 Docker
- Expo 개발 환경(Android Studio 또는 Xcode, 모바일 테스트 시)

### 설치 및 환경 변수

```bash
pnpm install
cp .env.example .env
```

`.env`에는 사용하는 환경에 따라 `DATABASE_URL`, `OPENAI_API_KEY`, Agora 인증 정보, Google Maps 키, AWS S3 정보와 모바일용 `EXPO_PUBLIC_*` 환경 변수를 설정합니다. 외부 AI API 없이 화면을 확인하려면 `AI_MOCK_MODE=true`를 사용할 수 있습니다.

### 데이터베이스 실행

```bash
docker compose -f infra/docker-compose.yml up -d postgres
pnpm db:generate
pnpm db:migrate
```

### 개발 서버 실행

모바일·웹·Worker를 동시에 실행하려면:

```bash
pnpm dev
```

개별 실행이 필요한 경우:

```bash
pnpm --filter mobile dev
pnpm --filter web dev
pnpm --filter worker dev
```

모바일 앱은 Expo 안내에 따라 Android 에뮬레이터, iOS 시뮬레이터 또는 Expo 개발 클라이언트에서 실행합니다.

## 보안 및 개인정보

사건 정보에는 위치, 연락처, 신고 내용과 같은 민감한 정보가 포함될 수 있습니다.

- API 키와 인증 정보는 `.env`에만 보관하고 저장소에 커밋하지 않습니다.
- 클라이언트에 노출되는 Google Maps 키는 허용 도메인·앱 식별자로 제한합니다.
- 서버 전용 키와 Agora 인증서는 모바일·웹 번들에 포함하지 않습니다.
- 비밀번호와 개인정보를 로그·에러 메시지·분석 이벤트에 남기지 않습니다.
- 임시 사건 데이터는 `DATA_RETENTION_DAYS` 정책에 따라 보관·삭제합니다.

## 개발 참고

모바일과 웹은 같은 도메인 모델과 View props를 공유합니다. 화면의 상태 관리·라우팅·API 호출은 Screen이 담당하고, 표현은 View가 담당합니다. 새로운 화면이나 API를 추가할 때는 `docs/USER_FLOW.md`와 공통 타입을 함께 확인해 플랫폼별 동작이 달라지지 않도록 합니다.
